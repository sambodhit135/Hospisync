# HospiSync Utility Scripts

This directory contains various Python scripts used for automation, data transfer, and documentation generation.

- `append_receiver_timer.py`: Automates receiving and applying data patches on a scheduled interval.
- `append_sender.py`: Handles packaging and sending data payloads to external receiver nodes.
- `append_transfer.py`: Core utility managing the data transfer lifecycle and payload structuring.
- `patch_transfer_ui.py`: Provides a lightweight Tkinter UI interface for managing and testing data patches.
- `rewrite_transfer.py`: Utility to rewrite or rebuild corrupted/incomplete data transfer payloads.
- `fetch_recommend_test.py`: A test script for simulating the recommendation engine's data fetching.
- `convert_md_to_docx.py`: Converts Markdown documentation files into Word Document (`.docx`) format.
- `generate_docx.py`: Automates the generation of the final comprehensive Word Document from multiple sources.
